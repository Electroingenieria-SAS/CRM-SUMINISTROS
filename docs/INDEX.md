# Índice documental CRM Suministros

## Vigente / operativo

Estos documentos describen el estado que debe usarse para operar o modificar el sistema:

- `README.md` — estado general y arquitectura productiva.
- `docs/IMPLEMENTATION_STATUS.md` — capacidades y pendientes actuales.
- `docs/SECURITY.md` — modelo de seguridad vigente.
- `docs/REPOSITORY_GOVERNANCE.md` — ramas, PR, CI y reglas de cambio.
- `docs/ARCHITECTURE.md` — arquitectura técnica.
- `docs/FUNCTIONAL_FLOWS.md` — flujo funcional.
- `docs/DEPLOYMENT.md` — promoción a producción.
- `docs/DEPLOYMENT_VERCEL_SUPABASE.md` — detalle de plataformas.
- `docs/OPERATIONS_RUNBOOK.md` — operación e incidentes.
- `docs/QA_RELEASE_CHECKLIST.md` — checklist de release.
- `docs/SECURITY_ADVISOR_BACKLOG.md` — observaciones del Advisor.
- `docs/AUDITORIA_INTEGRAL_2026-09-14.md` — última auditoría integral base.

## Histórico / evidencia de evolución

Los demás documentos versionados de releases anteriores (V10.x, V11.x, Paco, Recepción, cambios visuales y auditorías previas) se conservan como evidencia técnica y trazabilidad. No deben tomarse como especificación vigente cuando contradigan los documentos de la sección anterior.

## Regla documental

Cuando una release sustituya una decisión anterior:

1. actualizar los documentos vigentes;
2. conservar el documento histórico si aporta trazabilidad;
3. evitar duplicar una especificación activa en múltiples archivos;
4. enlazar desde este índice cualquier nuevo documento que pase a ser normativo.
